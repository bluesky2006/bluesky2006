## 📂 Projects

### 🌿 **Essentience** *(mobile app)*
A digital wellness card-deck app prototype built with **React Native**, **Expo Router**, and **NativeWind**.  
Local JSON data with planned **Supabase** sync for cloud storage and progress tracking.  
Clean design, category filters (Body / Heart / Mind / Soul) and search.  
**Links:** [GitHub (currently private)](https://github.com/bluesky2006/essentience-app) • [Essentience](https://www.essentience.net/)

---

### 🎧 **kr8** *(desktop + mobile ecosystem)*
A cross-platform record-bag manager for DJs.  
Desktop built with **Electron + React**, mobile companion in **React Native**, connected via **Supabase / PostgreSQL** for shared playlists and metadata.  
Focus on UI cohesion, data flow and local/remote sync. Co-programmed with [Joel Kram](https://github.com/pooch1e)  
**Links:** [GitHub - desktop](https://github.com/bluesky2006/kr8-desktop) • [GitHub - mobile](https://github.com/bluesky2006/kr8-mobile) • [GitHub - server](https://github.com/bluesky2006/kr8-server)

---

### 🖼️ **Cur8or** *(web app)*
Virtual exhibition curator using **Next.js + TypeScript + Tailwind**.  
Aggregates artworks from museum APIs (Cleveland / AIC) and lets users assemble virtual galleries via drag-and-drop.  
Built with **Framer Motion** for smooth transitions and **Embla Carousel** for artwork slideshows.  
Hosted on **Vercel**.  
**Links:** [GitHub](https://github.com/bluesky2006/cur8or) • [Live](https://cur8or.vercel.app/)

---

### ✨ **Glitterball** *(interactive microsite)*
A playful HTML/CSS/JS microsite for a Somerset club night — part flyer, part interactive poster.  
Randomised textures, colour palettes and animation cycles make each visit unique.  
**Links:** [GitHub](https://github.com/bluesky2006/glitterball) • [Live](https://glitterball.info/)

---

### 📰 **Northcoder News** *(solo project)*
Full-stack news aggregator inspired by Hacker News.  
**React + Vite** front-end, **Express + PostgreSQL** back-end, hosted on **Render + Netlify**.  
Includes voting, commenting and topic filtering.  
**Links:** [Live](https://nc-news-sgtb.netlify.app) • [API](https://nc-news-3jz4.onrender.com) • [FE Repo](https://github.com/bluesky2006/nc-news) • [BE Repo](https://github.com/bluesky2006/nc-news-be)

---

### 🤖 **reci-p.ai** *(group project)*
Cross-platform mobile app using **React Native**, **Expo**, and **MongoDB** that helps users recreate recipes from product photos via **OCR + Gemini AI**.  
Led agile planning in a 4-person team and integrated camera/photo upload, third-party APIs, and mobile deployment.  
**Links:** [GitHub](https://github.com/bluesky2006/reci-p.ai) • [Demo](https://www.northcoders.com/blog/reci-p-ai/e)
